# AIFMS
![image_2025-04-07_10-56-24](https://github.com/user-attachments/assets/66d1d10d-0d5c-4cae-9650-695f627114c4)

The AI Financial Management System (AIFMS) is made as a graduation project by two AOU CS graduates: AbdulAziz Mohammad & Hamza Wael. AIFMS offers fixed-income earners a tool for organized financial management. Users can input their income, expenses, and obligations into a centralized system, gaining a clear overview of their financial situation. A key feature is the integration of a specialized AI model designed to provide financial assistance. This AI analyzes user data to help organize expenses and increase financial awareness through tailored insights and recommendations.

*Note: the used AI model is still under development, so it may not be working perfectly, but it will be soon :)
